README — การแทรกลิงค์ด้วย HTML & CSS

วิชาการพัฒนาเว็บแอพสมัยใหม่  |  โรงเรียนจอมทอง  |  หัวข้อ: HTML & CSS เบื้องต้น

1. ภาพรวม

โค้ดนี้สร้าง การ์ดลิงค์เว็บไซต์ ที่มีรูปโลโก้และข้อความ คลิกได้ทั้งรูปและข้อความพร้อมกัน
แบ่งเป็น 2 ส่วนหลัก คือ <style> สำหรับกำหนดรูปแบบ และ <body> สำหรับโครงสร้างเนื้อหา

2. โครงสร้าง HTML — การ์ดแต่ละใบ
🔒 no copy
<!-- ใช้ <a> ครอบทั้งรูปและข้อความ คลิกได้ทุกจุด -->
<a class="site-card" href="https://www.google.com" target="_blank">
  <img src="URL_ของรูป" alt="google logo">
  <span>Google</span>
</a>
แท็ก / Attributeหน้าที่
<a class="site-card">ลิงค์ที่ใช้สไตล์การ์ด ครอบทั้งรูปและข้อความไว้ด้วยกัน
href="..."URL ปลายทางเมื่อคลิก
target="_blank"เปิดลิงค์ในแท็บใหม่
<img src="..." alt="...">แสดงรูปโลโก้ — alt คือข้อความเมื่อรูปไม่โหลด
<span>...</span>ข้อความชื่อเว็บไซต์ใต้รูป
3. CSS — .site-card (กล่องการ์ด)
🔒 no copy
/* การ์ดแต่ละเว็บไซต์ */
.site-card {
  display: inline-block;  /* เรียงต่อกันในแนวนอน */
  text-align: center;     /* จัดเนื้อหากึ่งกลาง */
  margin: 8px;           /* ระยะห่างรอบการ์ด */
  text-decoration: none;  /* ลบเส้นใต้ลิงค์ออก */
}
Propertyค่าหมายความว่า
display: inline-blockinline-blockวางการ์ดเรียงต่อกันในแนวนอน ไม่ขึ้นบรรทัดใหม่
text-align: centercenterจัดเนื้อหาในการ์ดให้อยู่กึ่งกลาง
margin: 8px8pxเว้นระยะห่างรอบการ์ดทุกด้าน
text-decoration: nonenoneลบเส้นใต้ลิงค์ปกติออก
4. CSS — .site-card img (รูปโลโก้)
🔒 no copy
/* รูปโลโก้ */
.site-card img {
  display: block;         /* ขึ้นบรรทัดใหม่ แยกจากข้อความ */
  width: 80px;
  height: 80px;
  object-fit: contain;    /* ย่อ/ขยายรูปโดยไม่บิดเบี้ยว */
  border: 2px solid #ddd; /* เส้นขอบบางสีเทาอ่อน */
  border-radius: 12px;    /* มุมโค้งมน */
  padding: 8px;         /* ช่องว่างระหว่างรูปกับขอบ */
  background: #fff;      /* พื้นหลังขาว ป้องกันโปร่งใส */
  transition: transform 0.2s; /* animation เวลา hover */
}
Propertyค่าหมายความว่า
display: blockblockรูปขึ้นบรรทัดใหม่ แยกจากข้อความด้านล่าง
width / height80pxกำหนดขนาดกรอบรูปให้เท่ากันทุกรูป
object-fit: containcontainย่อ/ขยายรูปให้พอดีกรอบโดยไม่บิดเบี้ยว
border2px solid #dddเส้นขอบบางสีเทาอ่อนรอบรูป
border-radius: 12px12pxทำให้มุมกรอบโค้งมน
padding: 8px8pxเว้นช่องว่างระหว่างรูปกับขอบกรอบ
background: #fff#fff (ขาว)พื้นหลังรูปเป็นสีขาว ป้องกันพื้นหลังโปร่งใส
transition: transform 0.2s0.2sทำให้การเปลี่ยนขนาดตอน hover ค่อยๆ เกิดขึ้น
5. CSS — .site-card span (ข้อความปุ่ม)
🔒 no copy
/* ข้อความปุ่ม */
.site-card span {
  display: block;       /* ขึ้นบรรทัดใหม่ใต้รูป */
  margin-top: 6px;    /* ระยะห่างระหว่างรูปกับข้อความ */
  font-size: 13px;    /* ขนาดตัวอักษร */
  color: #333;        /* สีเทาเข้ม */
  font-family: sans-serif; /* ฟอนต์ไม่มีหัว อ่านง่าย */
}
Propertyค่าหมายความว่า
display: blockblockข้อความขึ้นบรรทัดใหม่ใต้รูป
margin-top: 6px6pxเว้นช่องว่างระหว่างรูปกับข้อความ
font-size: 13px13pxขนาดตัวอักษร
color: #333#333 (เทาเข้ม)สีตัวอักษร
font-family: sans-serifsans-serifฟอนต์ไม่มีหัว อ่านง่าย
6. CSS — :hover (เอฟเฟกต์เมื่อเอาเมาส์ไปวาง)
🔒 no copy
/* เอฟเฟกต์เมื่อเอาเมาส์ไปวาง */
.site-card:hover img {
  transform: scale(1.1);   /* ขยายรูปขึ้น 10% */
  border-color: #4a90e2; /* ขอบเปลี่ยนเป็นสีน้ำเงิน */
}

.site-card:hover span {
  color: #4a90e2;        /* ข้อความเปลี่ยนเป็นสีน้ำเงินตาม */
}
Propertyค่าหมายความว่า
transform: scale(1.1)1.1ขยายรูปขึ้น 10% เมื่อเอาเมาส์ไปวาง
border-color: #4a90e2#4a90e2 (น้ำเงิน)เปลี่ยนสีขอบเป็นสีน้ำเงิน
color: #4a90e2#4a90e2 (น้ำเงิน)เปลี่ยนสีข้อความเป็นสีน้ำเงินตาม
💡 transition: transform 0.2s ที่กำหนดไว้ใน .site-card img ทำให้การ scale ค่อยๆ เกิดขึ้นใน 0.2 วินาที ไม่กระโดดทันที

8. แบบฝึกหัด — เขียนโค้ดด้วยตัวเอง

โค้ดด้านล่างคือไฟล์ทั้งหมด — ช่องสีเหลืองคือส่วนที่ต้องเปลี่ยนเอง อ่านคอมเมนต์เพื่อดูว่าต้องใส่อะไร

ช่องที่ต้องพิมพ์เอง โค้ดที่สำเร็จแล้ว ไม่ต้องเปลี่ยน
🔒 no copy
<!DOCTYPE html>
<html>
<head>
  <base target="_top">
  <style>
    .site-card {
      display: inline-block;
      text-align: center;
      margin: 8px;
      text-decoration: none;
    }

    .site-card img {
      display: block;
      width: 80px;
      height: 80px;
      object-fit: contain;
      border: 2px solid #ddd;
      border-radius: 12px;
      padding: 8px;
      background: #fff;
      transition: transform 0.2s;
    }

    .site-card span {
      display: block;
      margin-top: 6px;
      font-size: 13px;
      color: #333;
      font-family: sans-serif;
    }

    .site-card:hover img {
      transform: scale(1.1);
      border-color: #4a90e2;
    }

    .site-card:hover span {
      color: #4a90e2;
    }
  </style>
</head>
<body>

  <!-- เปลี่ยนเป็นหัวข้อของตัวเอง -->
  <h2></h2>

  <!-- เปลี่ยนเป็นข้อความแนะนำของตัวเอง -->
  <p></p>

  <!-- การ์ดที่ 1: เปลี่ยน href เป็น URL เว็บที่ชอบ -->
  <a class="site-card" href="" target="_blank">
    <!-- เปลี่ยน src เป็น URL รูปโลโก้ของเว็บนั้น -->
    <img src="" alt="">
    <!-- เปลี่ยนเป็นชื่อเว็บที่แสดงใต้รูป -->
    <span></span>
  </a>

  <!-- การ์ดที่ 2: เปลี่ยน href เป็น URL เว็บที่ชอบ -->
  <a class="site-card" href="" target="_blank">
    <img src="" alt="">
    <span></span>
  </a>

  <!-- การ์ดที่ 3: เปลี่ยน href เป็น URL เว็บที่ชอบ -->
  <a class="site-card" href="" target="_blank">
    <img src="" alt="">
    <span></span>
  </a>

</body>
</html>
✏️ คำแนะนำ: CSS ทั้งหมดสำเร็จแล้ว ไม่ต้องแก้ไข — ให้เปลี่ยนเฉพาะช่องสีเหลืองในส่วน <body> คือ หัวข้อ, ข้อความ, URL เว็บ, URL รูป และชื่อเว็บ
