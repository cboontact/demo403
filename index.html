2. CSS — คลาส .site-card (กล่องการ์ด)
/* การ์ดแต่ละเว็บไซต์ */
.site-card {
  display: inline-block;
  text-align: center;
  margin: 8px;
  text-decoration: none;
}
Propertyค่าหมายความว่า
display: inline-block inline-block วางการ์ดเรียงต่อกันในแนวนอน (ไม่ขึ้นบรรทัดใหม่)
text-align: center center จัดเนื้อหาในการ์ดให้อยู่กึ่งกลาง
margin: 8px 8px เว้นระยะห่างรอบการ์ดทุกด้าน 8 พิกเซล
text-decoration: none none ลบเส้นใต้ลิงค์ปกติออก
3. CSS — คลาส .site-card img (รูปโลโก้)
/* รูปโลโก้ */
.site-card img {
  display: block;
  width: 80px; height: 80px;
  object-fit: contain;
  border: 2px solid #ddd;
  border-radius: 12px;
  padding: 8px;
  background: #fff;
  transition: transform 0.2s;
}
Propertyค่าหมายความว่า
display: blockblockให้รูปขึ้นบรรทัดใหม่ แยกจากข้อความด้านล่าง
width / height80pxกำหนดขนาดกรอบรูปให้เท่ากันทุกรูป
object-fit: containcontainย่อ/ขยายรูปให้พอดีกรอบ โดยไม่บิดเบี้ยว
border2px solid #dddเส้นขอบบางสีเทาอ่อนรอบรูป
border-radius: 12px12pxทำให้มุมกรอบโค้งมน
padding: 8px8pxเว้นช่องว่างระหว่างรูปกับขอบกรอบ
background: #fff#fff (ขาว)พื้นหลังรูปเป็นสีขาว ป้องกันโปร่งใส
transition: transform 0.2s0.2sทำให้การเปลี่ยนขนาดตอน hover ค่อยๆ เกิดขึ้น ไม่กระตุก
4. CSS — คลาส .site-card span (ข้อความปุ่ม)
/* ข้อความปุ่ม */
.site-card span {
  display: block;
  margin-top: 6px;
  font-size: 13px;
  color: #333;
  font-family: sans-serif;
}
Propertyค่าหมายความว่า
display: blockblockข้อความขึ้นบรรทัดใหม่ใต้รูป
margin-top: 6px6pxเว้นช่องว่างระหว่างรูปกับข้อความ
font-size: 13px13pxขนาดตัวอักษร
color: #333#333 (เทาเข้ม)สีตัวอักษร
font-family: sans-serifsans-serifฟอนต์ไม่มีหัว อ่านง่าย
5. CSS — เอฟเฟกต์ :hover (เมื่อเอาเมาส์ไปวาง)
/* เอฟเฟกต์เมื่อเอาเมาส์ไปวาง */
.site-card:hover img {
  transform: scale(1.1);
  border-color: #4a90e2;
}

.site-card:hover span {
  color: #4a90e2;
}
Propertyค่าหมายความว่า
transform: scale(1.1)1.1ขยายรูปขึ้น 10% เมื่อเอาเมาส์ไปวาง
border-color: #4a90e2#4a90e2 (น้ำเงิน)เปลี่ยนสีขอบเป็นสีน้ำเงิน
color: #4a90e2#4a90e2 (น้ำเงิน)เปลี่ยนสีข้อความเป็นสีน้ำเงินตาม
💡 transition ที่กำหนดไว้ใน .site-card img ทำให้การ scale ค่อยๆ เกิดขึ้นใน 0.2 วินาที ไม่กระโดดทันที
6. โครงสร้าง HTML — การ์ดแต่ละใบ
<!-- ใช้ <a> ครอบทั้งรูปและข้อความ คลิกได้ทุกจุด -->
<a class="site-card" href="https://www.google.com" target="_blank">
  <img src="URL_ของรูป" alt="google logo">
  <span>Google</span>
</a>
แท็ก / Attributeหน้าที่
<a class="site-card">ลิงค์ที่ใช้สไตล์การ์ด ครอบทั้งรูปและข้อความไว้ด้วยกัน
href="..."URL ปลายทางเมื่อคลิก
target="_blank"เปิดลิงค์ในแท็บใหม่
<img src="..." alt="...">แสดงรูปโลโก้ — alt คือข้อความเมื่อรูปไม่โหลด
<span>...</span>ข้อความชื่อเว็บไซต์ใต้รูป
