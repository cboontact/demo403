# เอกสารอธิบายโค้ด — การแทรกลิงค์ด้วย HTML & CSS

> วิชาเทคโนโลยี | โรงเรียนจอมทอง | หัวข้อ: HTML & CSS เบื้องต้น

---

## ภาพรวม

โค้ดนี้สร้าง **การ์ดลิงค์เว็บไซต์** ที่มีรูปโลโก้และข้อความ โดยคลิกได้ทั้งรูปและข้อความพร้อมกัน  
แบ่งเป็น 2 ส่วนหลัก คือ `<style>` สำหรับกำหนดรูปแบบ และ `<body>` สำหรับโครงสร้างเนื้อหา

---

## โครงสร้าง HTML — การ์ดแต่ละใบ

```html
<!-- ใช้ <a> ครอบทั้งรูปและข้อความ คลิกได้ทุกจุด -->
<a class="site-card" href="https://www.google.com" target="_blank">
  <img src="URL_ของรูป" alt="google logo">
  <span>Google</span>
</a>
```

| แท็ก / Attribute | หน้าที่ |
|---|---|
| `<a class="site-card">` | ลิงค์ที่ใช้สไตล์การ์ด ครอบทั้งรูปและข้อความไว้ด้วยกัน |
| `href="..."` | URL ปลายทางเมื่อคลิก |
| `target="_blank"` | เปิดลิงค์ในแท็บใหม่ |
| `<img src="..." alt="...">` | แสดงรูปโลโก้ — `alt` คือข้อความเมื่อรูปไม่โหลด |
| `<span>...</span>` | ข้อความชื่อเว็บไซต์ใต้รูป |

---

## CSS — อธิบายทีละ Class

### 1. `.site-card` — กล่องการ์ด

```css
/* การ์ดแต่ละเว็บไซต์ */
.site-card {
  display: inline-block;  /* เรียงต่อกันในแนวนอน */
  text-align: center;     /* จัดเนื้อหากึ่งกลาง */
  margin: 8px;            /* ระยะห่างรอบการ์ด */
  text-decoration: none;  /* ลบเส้นใต้ลิงค์ออก */
}
```

| Property | ค่า | หมายความว่า |
|---|---|---|
| `display: inline-block` | inline-block | วางการ์ดเรียงต่อกันในแนวนอน ไม่ขึ้นบรรทัดใหม่ |
| `text-align: center` | center | จัดเนื้อหาในการ์ดให้อยู่กึ่งกลาง |
| `margin: 8px` | 8px | เว้นระยะห่างรอบการ์ดทุกด้าน |
| `text-decoration: none` | none | ลบเส้นใต้ลิงค์ปกติออก |

---

### 2. `.site-card img` — รูปโลโก้

```css
/* รูปโลโก้ */
.site-card img {
  display: block;         /* ขึ้นบรรทัดใหม่ แยกจากข้อความ */
  width: 80px;
  height: 80px;
  object-fit: contain;    /* ย่อ/ขยายรูปโดยไม่บิดเบี้ยว */
  border: 2px solid #ddd; /* เส้นขอบบางสีเทาอ่อน */
  border-radius: 12px;    /* มุมโค้งมน */
  padding: 8px;           /* ช่องว่างระหว่างรูปกับขอบ */
  background: #fff;       /* พื้นหลังขาว ป้องกันโปร่งใส */
  transition: transform 0.2s; /* animation เวลา hover */
}
```

| Property | ค่า | หมายความว่า |
|---|---|---|
| `display: block` | block | รูปขึ้นบรรทัดใหม่ แยกจากข้อความด้านล่าง |
| `width / height` | 80px | กำหนดขนาดกรอบรูปให้เท่ากันทุกรูป |
| `object-fit: contain` | contain | ย่อ/ขยายรูปให้พอดีกรอบโดยไม่บิดเบี้ยว |
| `border` | 2px solid #ddd | เส้นขอบบางสีเทาอ่อนรอบรูป |
| `border-radius: 12px` | 12px | ทำให้มุมกรอบโค้งมน |
| `padding: 8px` | 8px | เว้นช่องว่างระหว่างรูปกับขอบกรอบ |
| `background: #fff` | #fff (ขาว) | พื้นหลังรูปเป็นสีขาว ป้องกันพื้นหลังโปร่งใส |
| `transition: transform 0.2s` | 0.2s | ทำให้การเปลี่ยนขนาดตอน hover ค่อยๆ เกิดขึ้น |

---

### 3. `.site-card span` — ข้อความปุ่ม

```css
/* ข้อความปุ่ม */
.site-card span {
  display: block;       /* ขึ้นบรรทัดใหม่ใต้รูป */
  margin-top: 6px;      /* ระยะห่างระหว่างรูปกับข้อความ */
  font-size: 13px;      /* ขนาดตัวอักษร */
  color: #333;          /* สีเทาเข้ม */
  font-family: sans-serif; /* ฟอนต์ไม่มีหัว อ่านง่าย */
}
```

| Property | ค่า | หมายความว่า |
|---|---|---|
| `display: block` | block | ข้อความขึ้นบรรทัดใหม่ใต้รูป |
| `margin-top: 6px` | 6px | เว้นช่องว่างระหว่างรูปกับข้อความ |
| `font-size: 13px` | 13px | ขนาดตัวอักษร |
| `color: #333` | #333 (เทาเข้ม) | สีตัวอักษร |
| `font-family: sans-serif` | sans-serif | ฟอนต์ไม่มีหัว อ่านง่าย |

---

### 4. `:hover` — เอฟเฟกต์เมื่อเอาเมาส์ไปวาง

```css
/* เอฟเฟกต์เมื่อเอาเมาส์ไปวาง */
.site-card:hover img {
  transform: scale(1.1);     /* ขยายรูปขึ้น 10% */
  border-color: #4a90e2;     /* ขอบเปลี่ยนเป็นสีน้ำเงิน */
}

.site-card:hover span {
  color: #4a90e2;            /* ข้อความเปลี่ยนเป็นสีน้ำเงินตาม */
}
```

| Property | ค่า | หมายความว่า |
|---|---|---|
| `transform: scale(1.1)` | 1.1 | ขยายรูปขึ้น 10% เมื่อเอาเมาส์ไปวาง |
| `border-color: #4a90e2` | #4a90e2 (น้ำเงิน) | เปลี่ยนสีขอบเป็นสีน้ำเงิน |
| `color: #4a90e2` | #4a90e2 (น้ำเงิน) | เปลี่ยนสีข้อความเป็นสีน้ำเงินตาม |

> **หมายเหตุ:** `transition: transform 0.2s` ที่กำหนดไว้ใน `.site-card img` ทำให้การ scale ค่อยๆ เกิดขึ้นใน 0.2 วินาที ไม่กระโดดทันที
